# NaturvidaWeb

## Descripción del proyecto

NaturvidaWeb es una aplicación web desarrollada para la tienda naturista Naturvida, como parte de la evidencia **GA7-220501096-AA2-EV02 – Módulos de software codificados** del programa de formación ADSO del SENA.

El proyecto busca apoyar la gestión de la información de una tienda naturista mediante herramientas tecnológicas.

## Tecnologías utilizadas

- Java.
- JSP (JavaServer Pages).
- Servlets.
- HTML.
- MySQL.
- Apache Tomcat.
- NetBeans IDE.

## Módulo desarrollado

El proyecto incluye el módulo de gestión de productos, que permite realizar las operaciones CRUD:

- **Crear:** registrar nuevos productos.
- **Consultar:** visualizar los productos registrados.
- **Actualizar:** modificar la información de los productos.
- **Eliminar:** borrar registros de productos.

## Base de datos

El proyecto utiliza MySQL y cuenta con el archivo `tienda_naturista.sql`, que contiene la exportación de la base de datos.

Entre las tablas incluidas se encuentran:

- `tblcliente`
- `tblproducto`
- `tblproveedor`
- `tblusuario`
- `tblventa`

## Requisitos para ejecutar el proyecto

- Tener instalado Java JDK.
- Contar con Apache Tomcat 10.1.
- Tener instalado MySQL y MySQL Workbench.
- Utilizar NetBeans IDE.
- Incorporar el conector JDBC de MySQL al proyecto.

## Instalación y ejecución

1. Descargar o clonar el repositorio NaturvidaWeb.
2. Crear o importar la base de datos utilizando el archivo `tienda_naturista.sql`.
3. Configurar la conexión a MySQL en el proyecto mediante las credenciales locales.
4. Abrir el proyecto en NetBeans.
5. Configurar Apache Tomcat como servidor.
6. Ejecutar el proyecto y acceder al módulo de productos.
